A fix for Update now.

## Fixed
- **Update now** downloaded the new version but did not start the installer, so Reeve closed without updating. It now installs the update and opens Reeve again.

## Install
If you have 0.2.1 or 0.2.2, download `Reeve-0.2.2.1-setup.exe` below and run it once: Update now in those versions does not work. It updates your install and keeps your matches and settings. From this version on, updates arrive through the hub. Windows SmartScreen may warn about an unknown publisher, since the app is not code-signed yet: choose "More info", then "Run anyway".
