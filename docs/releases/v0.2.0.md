First release of Reeve, a lightweight macro assistant for Age of Empires IV. It reads the game's own UI (no game files, no memory reading) and warns you about the economy while you play.

## Install
Download `Reeve-0.2.0-setup.exe` below and run it. It installs for your user only (no admin rights). Windows SmartScreen may warn about an unknown publisher, since the app is not code-signed yet: choose "More info", then "Run anyway".

Play AoE4 in **Borderless** or **Windowed** mode: no overlay can draw over exclusive fullscreen.

## What it does
- **Live alerts** over the game, in three severities with their own sounds: idle villagers, town center not producing, housed (90% and 100% of the population cap) and floating resources, with limits per age.
- **Match reports** written when a match ends: villagers per resource, income per minute, stockpiles, population, ages reached and when each landmark started, and every alert on a timeline. Click any moment to see what was read then.
- **Hub** (double-click the tray icon): every recorded match with its report, and all the settings: alert thresholds, sounds per severity, volume, repetition, and your own sounds from any audio or video file.
- **Tray icon**: overlay on/off, debug view, mute, last report, data folder.
- **Housekeeping**: old matches are trimmed automatically (whole for 7 days, log and report up to 90 days, 500 MB at most; all adjustable).
- First-run notices: when the resource panel is found, and what to change if the game is in exclusive fullscreen.

## Requirements
Windows 10/11 (64-bit). The hub needs the Microsoft Edge WebView2 Runtime, included in Windows 11 and most Windows 10 installs; without it the alerts still work.

Your matches and settings live in `%APPDATA%\reeve` and are kept if you uninstall.
