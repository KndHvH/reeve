Automatic updates, alerts in your clips, and match cleanup.

## New
- **Updates from the hub**: Reeve checks GitHub once a day for a new version and tells you after your match. In the hub, **Update now** downloads it, closes Reeve, installs it and opens Reeve again. The daily check can be turned off in Settings, Updates, where you can also check right away.
- **Alerts in recordings and streams**: the alert cards now show in your clips, screen recordings and streams. Turn it off in Settings, Appearance, if you prefer them private.
- **Delete matches**: select one or more matches in the list to delete them, or delete a match from its report.

## Install
Download `Reeve-0.2.2-setup.exe` below and run it; it updates an existing install and keeps your matches and settings. From this version on, updates arrive through the hub. Windows SmartScreen may warn about an unknown publisher, since the app is not code-signed yet: choose "More info", then "Run anyway".
