Themes, rounded corners and a lighter Reeve.

## New
- **Themes**: choose the look of the hub, the match reports and the alert cards in Settings, Appearance: **Age** (gold on night blue, the default), **Dark**, **Dracula** and **Kitty** (light and pink). The hub changes at once and the alert cards follow within seconds.
- **Rounded corners**: square or rounded corners for the hub, the reports and the alert cards, with any theme.

## Improved
- Reeve is lighter: about 30 MB of memory, far less memory reserved in the background, fewer threads, and each reading of the game screen takes a fraction of the time it did.
- Matches where the game was only seen for a moment (a menu, a quick alt-tab) are no longer listed or kept.

## Fixed
- Quit in the tray menu now closes the hub too.
- Starting Reeve again while it runs brings up its hub instead of opening a second one.
- The alert timeline in the match report shows its colors again.

## Install
Download `Reeve-0.2.1-setup.exe` below and run it; it updates an existing install and keeps your matches and settings. Windows SmartScreen may warn about an unknown publisher, since the app is not code-signed yet: choose "More info", then "Run anyway".
