Step arrows for the build panel, gentler build alerts and a tidier hub.

## New
- **Arrows above the build panel**: when the panel is ahead of or behind your game, move the build one step back or forward. The rally point now sits on the same row, to their left. They can be turned off in Settings.
- **Build alerts grow with time**: when your villagers are not where the step puts them, the alert starts as info, turns into a warning after 6 seconds and critical after 12 (both adjustable). A resource that already reached the step's count stays reached, so a villager who leaves it to build is not an alert.
- **Quiet start**: no alerts during the first 10 seconds of a match.
- **The hub closes when a match starts**, to leave its memory to the game. Open it again from the tray; this can be turned off in Settings.

## Improved
- The match list shows only the time each alert was critical; the report keeps every alert.
- Build settings are now one Builds section in Settings, next to the panel preview. The Builds page keeps importing and managing builds, with a switch that turns build orders on or off.
- Rounded corners by default. A corner style you already chose is kept.
- Less CPU in the game's menus, and less memory reserved during matches.

## Fixed
- Long build names no longer spill over the build picker in the game's menus.

## Install
Use **Update now** in the hub, or download `Reeve-0.3.1-setup.exe` below and run it; it updates an existing install and keeps your matches and settings. Windows SmartScreen may warn about an unknown publisher, since the app is not code-signed yet: choose "More info", then "Run anyway".
