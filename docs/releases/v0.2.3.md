Animated alert cards, a preview of them in the hub, and a tidier match list.

## New
- **Card animations**: choose how an alert card appears, how it clears, and how the others move into its place: none, short fade, long fade or slide. By default cards slide in from the left edge, fade out slowly and slide into place. Settings, Appearance.
- **Card preview**: Settings, Appearance shows the alert cards in your theme and corner style, and plays each animation when you choose it.
- **Age IV floating limit**: floating resources can have a limit in Age IV too. It is empty by default, so large stockpiles late in the game are not flagged.

## Improved
- Alerts show as soon as a reading confirms them: "Show after" is 0 seconds by default.
- Match list: each alert keeps its own place in every row (TC idle, Idle, Housed, Floating), with a dot for the worst level it reached.
- Rounded corners: the severity color follows the card's outer edge cleanly.
- Kitty theme: raspberry text on a pale pink card, and the game icons on a small dark plate so they read clearly.
- Starting Reeve always shows something: started by hand it opens the hub; started with Windows it shows a notification.
- Match report: the age times line up, income reads "/min", and the version footer is gone.
- Settings, Appearance: animation choices as dropdowns and switches aligned to the right; the four floating limits fit on one line.

## Install
Use **Update now** in the hub, or download `Reeve-0.2.3-setup.exe` below and run it; it updates an existing install and keeps your matches and settings. If you are on 0.2.1 or 0.2.2, download and run the installer once (Update now did not work in those versions). Windows SmartScreen may warn about an unknown publisher, since the app is not code-signed yet: choose "More info", then "Run anyway".
